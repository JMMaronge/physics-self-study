# Physics Self-Study

A long-term, computation-supported study of physics beginning with John R. Taylor's
*Classical Mechanics*.

## Current milestone

Work through Taylor Chapters 1–3 while testing and refining the note-taking system.

## Working principles

1. Organize study around physical topics and mastery, not page completion.
2. Learn mathematics when the physics requires it.
3. Keep polished notes concise.
4. Use problem solutions to record reasoning and mistakes.
5. Use computation to test, visualize, and extend analytical results.
6. Add infrastructure only after it solves a real problem.

## Start here

1. Open `mechanics/curriculum.md`.
2. Begin with `mechanics/taylor/chapter-01-newtons-laws/README.md`.
3. Copy the templates only when you need a new topic or problem file.
4. Update `PROGRESS.md` at the end of each study session.
